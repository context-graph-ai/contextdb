# Performance result: find at 5,000,000 vectors on a 16-core desktop-class machine, 2026-11-14

## Promise

- Promise, in the product's words: "As a store grows, a vector search stays within the time the product promises". No figure promised.
- Counted test that guards it: none yet.

## Measurement

- Date: 2026-11-14; not taken again at revision `0c708a979` (a store of this size takes the better part of an hour to build); the figures below are of the fixed engine `cb9c072c687d1ab062ee90d9e4a460b2482cbab4` with measuring programs added (the final landing run of `numbers.sh` did not include this size)
- Program and command: `measure landed 5000000` on a built store of 5,000,000 sightings, reopened
- Data: 5,000,000 generated sightings of 768 numbers in one partition
- Passes and statistic: three passes, each value as printed; threads: 1; memory limit: 1,073,741,824 bytes (read session); release build
- Machine: AMD Ryzen 9 9955HX, 16 cores and 32 threads, 59 GiB of memory (a 16-core desktop-class build machine; not a user's machine); operating system: unknown; Rust toolchain: unknown; user's machine: no
- Settings that can change the result: search mode as named in the figures

## Limitations

- The recall of the ranked search is against the plain exact search; recall against the ranked exact search is not measured at this size.
- Time figures are of this machine only; no timed figure is a promise.
